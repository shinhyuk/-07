# GitHub Trending Top 5

GitHub에서 **주간** 및 **월간** 가장 인기 있는 저장소 TOP 5를 보여주는 웹 페이지입니다.

## 기능

- 주간 인기 저장소 TOP 5
- 월간 인기 저장소 TOP 5
- 스타 수, 포크 수, 사용 언어 표시
- 새로고침 버튼으로 최신 데이터 조회
- 다크 테마 GitHub 스타일 UI
- 모바일 반응형 레이아웃

## 사용 방법

`index.html`을 브라우저에서 열면 바로 사용할 수 있습니다. API 키 없이 GitHub Search API를 사용합니다.

> 비인증 요청은 시간당 10회로 제한됩니다. 자주 새로고침이 필요하면 GitHub Personal Access Token을 코드에 추가할 수 있습니다.
