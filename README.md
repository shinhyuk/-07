# 강남07 버스 도착정보

선정릉역에서 루첸타워로 가는 **강남07 마을버스**의 실시간 도착 예정 정보를 확인할 수 있는 웹 페이지입니다.

## 사용 방법

1. [서울 열린데이터광장](https://data.seoul.go.kr/)에서 회원가입 후 API 인증키를 발급받습니다.
2. `index.html`을 브라우저에서 열거나 웹 서버에 배포합니다.
3. API 인증키를 입력하고 저장하면 실시간 도착정보가 표시됩니다.

## 기능

- 강남07 버스 실시간 도착 예정 시간 표시
- 30초마다 자동 갱신
- 첫번째/두번째 도착 예정 버스 정보
- 다크 모드 지원 (시스템 설정 연동)
- 모바일 최적화 UI
- API 키 로컬 저장 (localStorage)

## 사용 API

- [서울 열린데이터광장 - 버스도착정보조회](https://data.seoul.go.kr/dataList/OA-1091/L/1/datasetView.do)
- 정류장 ARS 번호: `23214` (선정릉역)
